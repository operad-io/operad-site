环境变量

operad 或它的脚本读取的、或它启动的命令会收到的每个 OPERAD_* 变量，以及 operad 读取的其他变量。适合放进文件的设置在 config.json 中；对于每个 shell 或每台检查主机各不相同的值，请使用环境变量。

表中给出类型、默认值、接受的值以及值何时被读取。超出允许范围的值要么被忽略，要么被拒绝，并给出该行所指明的消息。

你设置的变量#

变量类型默认值允许的值何时生效
OPERAD_HOMEpath~/.operad目录路径每个命令：存放 config.json、store、secrets 目录、tui.json、keys.json、serve.lock 和 access-user.json 的 home。相对路径从当前目录解析。
OPERAD_SERVE_INTERVAL_MSinteger1000毫秒，大于 0operad serve 启动时：loop 两次之间的间隔。不是有限正数的值会回退到 1000。
OPERAD_BIND_RETRY_MSinteger10000毫秒，大于 0接替另一个 serve 的 serve 打开它的地址时：持续重试多久。第一次启动会立即失败。不是正数的值会回退到 10000。
OPERAD_BIND_RETRY_STEP_MSinteger250毫秒，大于 0同一次重试中两次尝试之间的等待。不是正数的值会回退到 250。
OPERAD_RELOAD_QUIET_MSinteger1000毫秒，大于 0文件需要保持多久不变，serve 才检查变更后的代码能否加载（见 Changed code）。不是正数的值会回退到 1000。
OPERAD_RELOAD_POLL_MSinteger5000毫秒，大于 0serve 多久查看一次文件是否有变化，以及 run 的进程多久等待一次无法加载的代码。不是正数的值会回退到 5000。
OPERAD_CHECK_BASEcommitHEAD 与 origin/main 的 merge basecommit 名称check-changed.sh 选取一项变更涉及的包时：用来比较的 commit。git 无法解析的名称会使脚本停止。
OPERAD_CHECK_HOSTssh destination未设置：检查在本机运行user@hostremote-check.sh 运行命令时：设置后，命令在该主机上运行。为空表示在本机。
OPERAD_CHECK_SLOTSinteger1整数，1 或更大主机上同时运行多少个任务检查；每个 slot 有自己的锁和 tree。其他任何值都会使脚本停止，并给出指明该变量的消息。
OPERAD_CHECK_LANEstring未设置integrationintegration 占用唯一的 integration slot，而不是任务 slot；其他任何值都会使脚本停止，并给出指明该变量的消息。
OPERAD_CHECK_TREEpathCode/operad相对于主机 home 的路径主机上运行检查所用的 clone；其他每个 slot 使用它的一个 worktree。
OPERAD_CHECK_PATH目录列表$HOME/.bun-operad/bin:$HOME/.bun/bin用 : 分隔的目录在检查行运行之前放到主机 PATH 的最前面，在主机上展开。
OPERAD_CHECK_SSHcommandssh -o BatchMode=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=4ssh 命令行检查连接它的主机时。
OPERAD_CHECK_SCPcommandscp -q -o BatchMode=yesscp 命令行检查把 bundle 复制到它的主机时。
OPERAD_TEST_PARALLELinteger2整数，1 或更大run-tests.sh 启动时：有多少个 worker 进程运行测试文件。其他任何值都会使脚本停止，并输出 run-tests: OPERAD_TEST_PARALLEL must be a whole number of 1 or more, not '<value>'。
OPERAD_TEST_HEAVY_PARALLELinteger8整数，1 或更大run-tests.sh 启动时：有多少个 worker 进程运行 heavy 测试文件（位于 test/heavy/ 下）。其他任何值都会使脚本停止，并给出指明该变量的消息。
OPERAD_TEST_OVERLAPinteger11 让 heavy step 与 light step 同时运行；0 让它在 light step 之后运行run-tests.sh 启动时。
OPERAD_TEST_HEARTBEAT_SECSinteger60整数秒数，或 0 表示关闭run-tests.sh 启动时：它多久检查一次某个 step 的报告或输出是否增长，增长时打印一行 heartbeat。静默的 step 不打印任何内容。
OPERAD_TEST_TIMESpath~/.operad-test-times文件路径每次完整的测试运行在此追加一行耗时记录（run-tests.sh 和 test-times.ts）。

operad 设置的变量#

这些变量是为 operad 启动的命令设置的。不要自己设置；你设置的值会被替换或移除。

变量类型默认值允许的值何时生效
OPERAD_IDstring总是设置处于等待的对象的 id，形式为 <type>:<id>在 notify command 的环境中。
OPERAD_TITLEstring总是设置对象的 title，读不到 title 时为它的 id在 notify command 的环境中。
OPERAD_REASONstring总是设置问题或等待的原因在 notify command 的环境中。
OPERAD_LINKstring总是设置operad://objects/<id> 链接在 notify command 的环境中（见 Links）。
OPERAD_TASKstring总是设置任务 id在 dev cleanup 或 integration 命令的环境中。
OPERAD_WORKTREEpath总是设置任务的 worktree在 dev cleanup 或 integration 命令的环境中。
OPERAD_REMOTEstring总是设置remote 的名称在 dev cleanup 或 integration 命令的环境中。
OPERAD_RUNstring总是设置<run id>:<step>在 step 的进程的环境中：它指明 run 和 step，使 serve 能找到 step 留下的仍在运行的东西。移除它的子进程不会被回收。
OPERAD_RUN_HOMEpath总是设置home 路径在 step 的进程的环境中，使两个 home 永不相遇。
OPERAD_SERVE_SUPERVISEDflag未设置1由因代码变更而重启 serve 的进程设置；在子进程看到自己的环境之前被移除。不要自己设置。
OPERAD_SERVE_REPLACESflag未设置1设置在由卡住的 serve 启动来取代它的那个 serve 上；在子进程看到自己的环境之前被移除。不要自己设置。

operad 读取的其他变量#

变量类型默认值允许的值何时生效
EDITORcommand未设置编辑器命令行operad dev task edit，当 stdin 是终端或没有带来 brief 时：编辑器打开当前的 brief。它通过 /bin/sh -c '<editor> "$1"' 运行。非零退出会使命令失败，并给出 "<editor>" exited with code <n>。
VISUALcommand未设置编辑器命令行仅在 EDITOR 未设置时使用。EDITOR 设为空值或空白值时不会回退到 VISUAL；命令会报告没有设置编辑器。
HOMEpath该账户的 home目录路径默认的 home（~/.operad）、~ 展开以及 radian 配置路径。
PATH目录列表该账户的 PATH用 : 分隔的目录查找 radian、pi、claude、git 以及命令启动的其他程序。不带 / 的命令名必须在 PATH 中。
RADIAN_CONFIGpath$HOME/.radian/config/config.toml文件路径radian harness 从该文件读取它自己的 provider 设置。
BASH_ENVpath未设置文件路径pi worker 在启动之前把它从自己的环境中删除，因此 shell 启动文件不能改变工具调用。
ENVpath未设置文件路径出于同样的原因被 pi worker 删除。
TMPDIRpath系统临时目录目录路径传给 bot 的 MCP server，使该 server 能找到临时文件。
LANGstring未设置locale 名称传给 bot 的 MCP server。
STRESS_LOCKpath$HOME/.operad-stress.lock目录路径scripts/stress.sh：本机上所有 stress 运行共用的锁。只有知道自己是唯一一个的运行才传 --no-lock。
NODE_ENVstring未设置test内部使用：当它为 test 时，插件注册表会省略仅用于测试的检查。正常使用时不要设置。
