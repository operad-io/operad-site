operad

operad 是面向编码 agent 的开放编排层。它让 agent（radian、Claude Code、pi 等）按经过验证的 flow 运行，把发生过的事保留为 history，并在工作需要人的地方联系到人：终端客户端、手机 app、通知、chat。你会看到三类内容：flow、等待人处理的事项（pending）、以及每个 step 做了什么和原因（history）。其余功能由插件提供，例如 dev 插件的计划和任务。

页面#

  • quickstart：创建 home，启动 serve，打开客户端。
  • setup-prompt：让你的 agent 编写 .operad/dev.json 的 prompt。
  • config：home 以及 config.json 的每个部分。
  • dev：dev.json 和 dev 插件的命令、reviewer、worker 与 pool。
  • access：访问 profile、access-user.json 和 always allow。
  • cli：每个命令和选项。
  • tui：终端客户端、它的主题和按键。
  • app：配对与手机 app。
  • http：/v1 端点、事件和错误。
  • mcp：供 lead agent 使用的 MCP server。
  • chats-and-bots：与 agent 的 chat，以及 bot。
  • notifications：notify 命令。
  • checks：检查一项变更，以及复现不稳定的测试。
  • environment：每个环境变量。
  • troubleshooting：出问题时怎么办。

完整的工作流见 Running operad on operad。插件作者从 Writing a plugin 开始。
