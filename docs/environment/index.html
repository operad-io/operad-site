Environment variables

Every OPERAD_* variable that operad or its scripts read, or that a command it starts receives, and the other variables operad reads. config.json holds the settings that belong in a file; use the environment for a value that changes per shell or per check host.

The tables give the type, the default, the values accepted and when the value is read. A value outside the allowed set is either ignored or refused with the message named in the row.

What you set#

VariableTypeDefaultAllowed valuesWhen it takes effect
OPERAD_HOMEpath~/.operadA directory pathEvery command: the home that holds config.json, the store, the secrets directory, tui.json, keys.json, serve.lock and access-user.json. A relative path is resolved from the current directory.
OPERAD_SERVE_INTERVAL_MSinteger1000milliseconds, more than 0When operad serve starts: the time between loop passes. A value that is not a finite positive number falls back to 1000.
OPERAD_BIND_RETRY_MSinteger10000milliseconds, more than 0When a serve that took over from another one opens its addresses: how long it keeps trying. A first start fails at once. A value that is not a positive number falls back to 10000.
OPERAD_BIND_RETRY_STEP_MSinteger250milliseconds, more than 0The wait between two tries of the same retry. A value that is not a positive number falls back to 250.
OPERAD_RELOAD_QUIET_MSinteger1000milliseconds, more than 0How long the files must be quiet before serve checks that changed code loads (see Changed code). A value that is not a positive number falls back to 1000.
OPERAD_RELOAD_POLL_MSinteger5000milliseconds, more than 0How often serve looks at the files for a change, and how often a run's process waits for code that does not load. A value that is not a positive number falls back to 5000.
OPERAD_CHECK_BASEcommitthe merge base of HEAD and origin/mainA commit nameWhen check-changed.sh picks the packages a change touches: the commit it compares with. A name git cannot resolve stops the script.
OPERAD_CHECK_HOSTssh destinationunset: the check runs hereuser@hostWhen remote-check.sh runs a command: with it set, the command runs on that host. Empty means here.
OPERAD_CHECK_SLOTSinteger1whole number, 1 or moreHow many task checks run at once on the host; each slot has its own lock and tree. Any other value stops the script with a message that names the variable.
OPERAD_CHECK_LANEstringunsetintegrationintegration takes the one integration slot instead of a task slot; any other value stops the script with a message that names the variable.
OPERAD_CHECK_TREEpathCode/operadA path relative to the host's homeThe clone on the host the checks run in; every other slot uses a worktree of it.
OPERAD_CHECK_PATHlist of directories$HOME/.bun-operad/bin:$HOME/.bun/binDirectories separated by :Put first on the host's PATH before the check line runs, expanded on the host.
OPERAD_CHECK_SSHcommandssh -o BatchMode=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=4An ssh command lineWhen a check connects to its host.
OPERAD_CHECK_SCPcommandscp -q -o BatchMode=yesAn scp command lineWhen a check copies the bundle to its host.
OPERAD_TEST_PARALLELinteger2whole number, 1 or moreWhen run-tests.sh starts: how many worker processes run test files. Any other value stops the script with run-tests: OPERAD_TEST_PARALLEL must be a whole number of 1 or more, not '<value>'.
OPERAD_TEST_HEAVY_PARALLELinteger8whole number, 1 or moreWhen run-tests.sh starts: how many worker processes run the heavy test files (under test/heavy/). Any other value stops the script with a message that names the variable.
OPERAD_TEST_OVERLAPinteger11 runs the heavy step beside the light step; 0 runs it after the light stepWhen run-tests.sh starts.
OPERAD_TEST_HEARTBEAT_SECSinteger60a whole number of seconds, or 0 to turn it offWhen run-tests.sh starts: how often it checks whether a step's report or output grew, and prints a heartbeat line when it did. A silent step prints nothing.
OPERAD_TEST_TIMESpath~/.operad-test-timesA file pathWhere each full test run appends one line of timings (run-tests.sh and test-times.ts).

What operad sets#

These are set for a command operad starts. Do not set them yourself; a value you set is replaced or removed.

VariableTypeDefaultAllowed valuesWhen it takes effect
OPERAD_IDstringalways setThe waiting object's id, as <type>:<id>In the environment of the notify command.
OPERAD_TITLEstringalways setThe object's title, or its id when the title cannot be readIn the environment of the notify command.
OPERAD_REASONstringalways setThe question or reason it waitsIn the environment of the notify command.
OPERAD_LINKstringalways setAn operad://objects/<id> linkIn the environment of the notify command (see Links).
OPERAD_TASKstringalways setA task idIn the environment of a dev cleanup or integration command.
OPERAD_WORKTREEpathalways setThe task's worktreeIn the environment of a dev cleanup or integration command.
OPERAD_REMOTEstringalways setThe remote's nameIn the environment of a dev cleanup or integration command.
OPERAD_RUNstringalways set<run id>:<step>In the environment of a step's process: it names the run and the step, so serve can find what a step left running. A child that removes it is not reaped.
OPERAD_RUN_HOMEpathalways setThe home pathIn the environment of a step's process, so two homes never meet.
OPERAD_SERVE_SUPERVISEDflagnot set1Set by the process that restarts serve on changed code; removed before the child sees its own environment. Do not set it yourself.
OPERAD_SERVE_REPLACESflagnot set1Set on a serve that a stuck one started in its place; removed before the child sees its own environment. Do not set it yourself.

Other variables operad reads#

VariableTypeDefaultAllowed valuesWhen it takes effect
EDITORcommandunsetAn editor command lineoperad dev task edit, when stdin is a terminal or carries no brief: the editor opens the current brief. It is run through /bin/sh -c '<editor> "$1"'. A non-zero exit fails the command with "<editor>" exited with code <n>.
VISUALcommandunsetAn editor command lineUsed only when EDITOR is unset. EDITOR set to an empty or blank value does not fall back to VISUAL; the command reports that no editor is set.
HOMEpaththe account's homeA directory pathThe default home (~/.operad), ~ expansion, and the radian config path.
PATHlist of directoriesthe account's PATHDirectories separated by :Finding radian, pi, claude, git and the other programs a command starts. A command named without a / must be on PATH.
RADIAN_CONFIGpath$HOME/.radian/config/config.tomlA file pathThe radian harness reads its own provider settings from this file.
BASH_ENVpathunsetA file pathThe pi worker deletes it from its own environment before it starts, so a shell startup file cannot change a tool call.
ENVpathunsetA file pathDeleted by the pi worker for the same reason.
TMPDIRpaththe system temporary directoryA directory pathPassed to a bot's MCP server, so the server can find temporary files.
LANGstringunsetA locale namePassed to a bot's MCP server.
STRESS_LOCKpath$HOME/.operad-stress.lockA directory pathscripts/stress.sh: the lock shared by every stress run on the machine. Only a run that knows it is alone passes --no-lock.
NODE_ENVstringunsettestInternal: the plugin registry leaves out a test-only check when it is test. Do not set it for normal use.
